# C Image-Processing Library

Procedural C image-processing project built around modular source files,
headers, a Makefile, and the `stb_image` single-header image library.

## Structure

| Path | Purpose |
| --- | --- |
| `src/main.c` | Program entry point and project workflow |
| `src/imageutil.c`, `src/imageutil.h` | Image loading, transformation, and output helpers |
| `src/helpers.c`, `src/helpers.h` | Supporting utility functions |
| `stb_image/` | Third-party image read/write/resize headers |
| `project-brief.pdf` | Original coursework brief |

## Skills Demonstrated

C programming, dynamic memory management, source/header separation, Makefiles,
matrix-style image operations, modular design.
