# Lab 7 — Agentic AI: REST APIs, Local LLMs, and Adaptive Monitoring

Built a multi-agent monitoring system using REST APIs, locally-hosted
language models (Ollama), and adaptive escalation logic.

## Key Work
- REST API design and consumption for agent communication
- Local LLM integration via Ollama for natural-language reasoning
- Multi-agent architecture: specialised agents per monitoring domain
- Adaptive escalation: agents trigger responses based on observed signals

## Key Skills
Python, REST APIs, Ollama (local LLM), multi-agent systems,
agentic workflow design, adaptive escalation, Docker
