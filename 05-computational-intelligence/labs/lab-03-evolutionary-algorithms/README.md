# Lab 3 — Ecosystem Stability Optimisation with Evolutionary Algorithms

Designed and solved a multi-parameter optimisation problem: finding initial
conditions for a three-species predator-prey-resource simulation that maintained
stable coexistence across 100 stochastic steps. Implemented and compared
Evolution Strategy (ES) and Genetic Algorithm (GA).

## Key Skills
Python, NumPy, Evolution Strategies, Genetic Algorithms, fitness function design,
stochastic simulation, multi-objective optimisation, agent-based modelling
