# Lab 5 — Reinforcement Learning Agent Design and Evaluation

Implemented five RL algorithms from scratch on a custom 5x5 Gridworld MDP:
First-Visit Monte Carlo, TD(0), Q-Learning, SARSA, and linear function
approximation with semi-gradient Q-learning.

## Algorithms Implemented
1. First-Visit Monte Carlo prediction
2. TD(0) prediction
3. Q-Learning (off-policy)
4. SARSA (on-policy)
5. Linear Function Approximation with semi-gradient Q-learning

## Key Skills
Python, NumPy, MDP design, Monte Carlo methods, TD learning,
Q-learning, SARSA, epsilon-greedy exploration, function approximation,
policy visualisation
