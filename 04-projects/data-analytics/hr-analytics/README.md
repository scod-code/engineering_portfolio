# HR Analytics — Employee Data

Processing and analysis of employee records across multiple data formats.

## Dataset

| File | Description |
|------|-------------|
| `data/employees_full.json` | Full employee records |
| `data/employees_v1.json` through `employees_v3.json` | Versioned subsets |
| `data/employee_data_processed.pkl` | Pre-processed Pandas DataFrame |

## Skills Demonstrated

Multi-format data ingestion (JSON, PKL), Pandas DataFrame operations,
workforce data processing and aggregation
