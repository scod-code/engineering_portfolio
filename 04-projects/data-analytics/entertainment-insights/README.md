# Entertainment Insights — Netflix Titles

Exploratory analysis of Netflix titles dataset examining content distribution
and feature relationships.

## Dataset

`data/netflix_titles.csv` — Netflix catalogue with title metadata including
type, country, release year, rating, and duration.

## Outputs

| File | Description |
|------|-------------|
| `outputs/jointplot_analysis_01.png` | Joint distribution plot — first variable pair |
| `outputs/jointplot_analysis_02.png` | Joint distribution plot — second variable pair |
| `outputs/pairplot_example_01.png` | Pairplot of dataset features |
| `outputs/pairplot_example_02.png` | Pairplot with categorical colour encoding |

## Skills Demonstrated

Pandas EDA, Seaborn jointplot and pairplot, distribution analysis,
multi-variable relationship visualisation
