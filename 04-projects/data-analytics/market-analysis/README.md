# Market Analysis — DMA Dataset

Exploratory analysis of a direct marketing dataset examining relationships
between marketing variables and response outcomes.

## Dataset

`data/dma_marketing_dataset.csv` and `.xlsx` — direct marketing records
available in both CSV and Excel formats.

## Outputs

| File | Description |
|------|-------------|
| `outputs/heatmap_correlation_matrix.png` | Correlation matrix across all numeric features |
| `outputs/scatterplot_multivariate.png` | Multivariate scatter plot of key variable relationships |

## Skills Demonstrated

Pandas data loading, correlation analysis, Seaborn heatmaps, Matplotlib scatter plots
