# Data Visualisation

A gallery of visualisation techniques demonstrating a range of chart types
and statistical graphics produced using Matplotlib and Seaborn.

## Outputs

| File | Chart Type |
|------|-----------|
| `outputs/subplots_example_01.png` | Multi-panel subplot layout |
| `outputs/subplots_example_02.png` | Alternative subplot configuration |
| `outputs/violinplot_distribution.png` | Violin plot showing distribution shape and spread |
| `outputs/histogram_boxplot_comparison.png` | Side-by-side histogram and boxplot |
| `outputs/plot_comparison_01.png` through `plot_comparison_05.png` | Multi-figure comparison series |

## Skills Demonstrated

Matplotlib subplots, Seaborn violin and distribution plots,
figure layout and sizing, comparative visualisation design
