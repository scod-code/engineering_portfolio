### 3. Multimodal Emotion Recognition System (88.7% Accuracy)
**Location:** `Artificial Perception/Coursework/coursework_artificial_perception/`

Classifies 8 emotions from audio and video:
- **Audio:** MFCC ablation (13, 20, 40 coefficients), F0, RMS energy, zero-crossing rate
- **Video:** 68 facial landmarks, 3 head pose angles, 20 action units
- **Fusion:** Weighted probability, logistic regression meta-classifier, early-fusion MLP (256→128→64)
- **Result:** 88.7% accuracy (early-fusion MLP) vs. 63.2% audio-only and 71.5% video-only
- **Datasets:** RAVDESS (1,440 audio clips) + FELT (facial features), auto-downloaded on first run

**Key Achievement:** Feature-level fusion outperforms decision-level combination; integration architecture matters

---

### 4. Federated Learning with Adversarial Robustness
**Location:** `05-computational-intelligence/federated-learning/`

Simulates production failure conditions:
- **Setup:** 12 clients with non-IID data, FGSM adversarial training, sign-flip poisoning attacks
- **Optimization:** Optuna TPE Bayesian search (5D: learning rate, weight decay, adversarial strength, aggregation strategy, trim ratio)
- **Result:** Composite score 0.9947 in 30 trials — outperforms random search on exact failure modes
- **Aggregation:** Mean, median, trimmed mean strategies evaluated

**Key Achievement:** Finds solutions in failure modes (unstable learning rates, mismatched aggregation) that random search misses

---

### 5. EEG Signal Processing & Feature Engineering (95.1% Accuracy)
**Location:** `05-computational-intelligence/signal-processing/`

Classifies EEG signals from high-noise sensor data:
- **Preprocessing:** 4th-order Butterworth band-pass (1-40 Hz), IIR notch (50 Hz, zero-phase)
- **Features:** 247-dimensional vector (time-domain statistics, Hjorth parameters, Welch PSD, STFT)
- **Feature Selection:** MI, RFE, RF importance evaluated across 3 classifiers
- **Result:** 95.1% balanced accuracy (RF + Logistic Regression) vs. 86.7% raw features — 8.4pp gain from engineering alone

**Key Achievement:** Disciplined feature engineering outperforms raw-feature baseline

---

### 6. Computer Vision: Classical & Deep Learning
**Location:** `Artificial Perception/Lecture 2-4/`

Comprehensive CV pipeline:
- **Classical:** ORB (701 RANSAC-filtered inliers), SIFT (164 good matches) on illumination-variant images
- **Deep Learning:** Custom CNN, VGG16 fine-tuning (ImageNet weights, last 4 layers unfrozen)
- **Transfer Learning:** Understanding when to train from scratch, freeze layers, use lower learning rates
- **Out-of-Distribution:** Documented failure modes (lion, wolf classified with confidence on Cats vs. Dogs model)

**Key Achievement:** Feature-level fusion and proper transfer learning strategy matter more than model choice

---

### 7. Reinforcement Learning: Autonomous Navigation
**Location:** `05-computational-intelligence/reinforcement-learning/`

Implemented 5 RL algorithms on bespoke MDP gridworld:
- **Algorithms:** First-Visit Monte Carlo, TD(0), Q-learning, SARSA, semi-gradient linear function approximation
- **Benchmark:** 3,000 training episodes each
- **Finding:** Q-learning converges faster but routes toward penalty zone; SARSA finds safer, longer path
- **Implication:** Speed-vs-safety tradeoff with direct deployment implications

**Key Achievement:** Demonstrates scalability toward real-world environments via function approximation

---

### 8. NLP Text Classification at Scale (18,846 Documents)
**Location:** `Artificial Perception/Lecture 7/`

Large-scale text classification:
- **Comparison:** Bag-of-Words (58.6%) vs. TF-IDF (69.3%) — feature representation matters more than classifier
- **Optimization:** Porter stemming (17.3% vocabulary reduction), chi-squared feature selection (65s → <1s)
- **Result:** Production-scale deployment on time-sensitive workloads

**Key Achievement:** Feature engineering and representation choice drive performance more than model complexity
